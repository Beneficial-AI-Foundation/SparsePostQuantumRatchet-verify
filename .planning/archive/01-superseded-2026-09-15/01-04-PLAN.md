- **No `eval`, no interpolated command strings.** Write each body to a `mktemp` file and
  pass `--body-file`. Property text contains backticks, `$`, `‖`, `⦃ ⦄` and quotes; the old
  script's `eval` shape (`issues/create_issues.sh:28-34,79-88`) is a correctness and

  seconds, which is exactly the window this plan's own idempotency test runs in; and
  `gh --jq` does not accept `jq`'s `--arg`. See the filing step for the authoritative
  algorithm.
- **No second copy of the issue body text.** The template is the shape, the catalog and
  `.planning/REQUIREMENTS.md` are the prose (D-05: one source of truth).
