<objective>
Run the gate script for the first time: build the tree, settle the `#print axioms` output
format empirically, build the `origin/main` baseline, execute all five gates, cross-check
the verdict against CI, and prove every gate can fail.

Purpose: INFRA-03 and ROADMAP criterion 1. Plan 01-02 wrote a script nobody has run, and
two of its gate-4 patterns are training knowledge rather than observed fact. A gate that
has never failed is not known to work.

matrix with literal output pasted into the SUMMARY.
</objective>

       `unknown identifier`, not a vacuous pass.

       without `--allow-sorry` and PASS with it; record both.

       gate 4 **FAILS** naming it.

       default width - force it. `format.width` is a registered builtin option in this
       toolchain (`Lean/Data/Format.lean:23`, verified 2026-09-14), and the axiom list is

       ```lean
       set_option format.width 20
       #print axioms <thm>
       ```
