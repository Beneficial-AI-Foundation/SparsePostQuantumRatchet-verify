<objective>
Retrofit provenance onto the catalog: give every property row a `Source:` citation that
resolves, and create the two reference lists gate 5 checks section and figure numbers
against.

Purpose: PROV-01, and ROADMAP criterion 2. The C2 criterion — "not invented" — is
unenforceable while a row's grounding lives only in a section heading or in a reviewer's
memory. After this plan, a row that claims a source the tree does not have fails a gate.
Output: an edited catalog and two reference lists. No Lean, no `src/`.
</objective>

<phase_type>
Documentation phase; zero `*.lean` files, zero `src/` and `SrcTranslated/` hunks,
`allowed_sorries: 0`. The catalog's **statements** are not edited here — only their
citations. A statement change is plan 01-08's business (D1-D5) or 01-07's (new rows).
</phase_type>

The three citation forms, from PROV-01:
- `Source: Spec §x.y` — ML-KEM Braid Rev. 1, last updated 2025-09-26
- `Source: SCKA Def. n` or `Source: SCKA Fig. n` — Auerbach, Dodis, Jost, Katsumata,
  Schmidt, *How to Compare Bandwidth Constrained Two-Party Secure Messaging Protocols*
- `Source: src/path.rs:a-b` — the code at `d47083c`

A row may carry more than one citation when it genuinely has more than one ground (a spec
section **and** the code lines implementing it), semicolon-separated. **Every** listed
citation must resolve — a row is not rescued by one good citation beside a broken one. This is
PROV-01 as ruled 2026-09-15; `REQUIREMENTS.md` PROV-01 and `PROJECT.md` § Constraints carry
the same wording, so do not re-derive the grammar from an older draft.

Anything that is not one of the three source classes — a `Spqr/Specs/**` lemma, a planning
doc — goes on a separate `Evidence:` line, which gate 5 ignores.

What the catalog already gives you: section headings carry the spec section (`## 7.
Ratcheted authenticator (§2.4)`), §10 and §11 rows carry a Code column, and many prose rows
cite `file.rs:line` inline. Most of this plan is promoting existing information into a
uniform, machine-checkable field — not researching from scratch.
</context>
