    Write `scripts/check-provenance.py` (stdlib only, no pip installs). It must:

    1. **Enumerate every property row** of `docs/spqr-properties.md` into one normalised ID
       registry: every `### PROP-…` / `### LEAN-…` / `### STRUCT-…` heading (the `STRUCT-`
       prefix matters — plan 01-07 adds two such rows), and every ID-bearing row of the §10 and
       §11 tables. A deviation ID appearing in **both** §11 tables — the existing five-column
       table and the Decision/Status table plan 01-08 adds — is **one** registry entry, joined
       by ID, not two rows each needing their own citation.

       Print the registry size. The measured counts on 2026-09-15 are: 28 `###` headings, 9 §10
       rows, 5 §11 deviation rows — **42** entries — against **38** rows in the §12 index,
       which differ because §12 collapses D1–D5 into a single aggregate entry
       (`docs/spqr-properties.md:490`). So do **not** assert equality with the index length, and
       do not use the figure 39, which matches neither count.

       Instead check **ID-set agreement**, which is the property that actually matters: every
       non-deviation registry ID appears in the §12 index and vice versa, with D1–D5 mapped to
       the aggregate entry. A missing ID on either side is a failure. Fail as well if the
       registry is smaller than 37 non-deviation entries — enumerating half the catalog is the
       failure mode to prevent, and a bare count floor is the backstop for it.
    2. **Require a `Source:` field** per row. Report every row lacking one.
    3. **Parse the `Source:` field** as a **semicolon-separated list of one or more**
       citations (PROV-01 as ruled 2026-09-15: "at least one of", and **every** listed
       citation must resolve — one good citation does not rescue a bad one). A row's
       `Evidence:` line, if present, is **not** parsed and **not** gated: it carries pointers
       outside the three source classes, such as a `Spqr/Specs/**` lemma. Each citation in the
       list must parse as one of three forms:
       - `Spec §x.y` — checked for membership in `docs/spec-sections.txt`, a one-per-line
         list of valid ML-KEM Braid Rev. 1 section numbers. The PDF is not parsed; the list
         is the checkable proxy and plan 01-03 creates it.
       - `SCKA Def. n` / `SCKA Fig. n` — checked against `docs/scka-refs.txt`, same shape.
       - `src/path.rs:a-b` or `src/path.rs:a` — the file must exist and the line numbers
         must be within its length. This is the strongest of the three and the one most
         likely to rot.
    4. **Fail on anything unparseable.** An unrecognised citation form is a failure, not a
       skip — otherwise a typo buys a pass. This is why a Lean path belongs on `Evidence:` and
       never in `Source:`.
    5. Exit 0 only if every row has a resolving citation; print a per-row table of failures.
       Support `--verbose` to print all rows and `--row <ID>` to check one.

    Wire it into `check-gates.sh` as gate 5: `python3 scripts/check-provenance.py`. Gate 5
    needs no build, so it must run even when `--gates 5` is given alone on an unbuilt tree.

    (recorded in plan 01-04)` line for 01-04 to fill in.
  </action>
